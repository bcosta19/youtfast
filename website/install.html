Commands go in a terminal: copy each block and paste it. Each Linux block downloads into the folder the terminal is in, your home folder when it opens.

Native Linux playback requires libmpv 0.42+ with Lua, in addition to glibc 2.39+. Check your installed libmpv package version; the distributions below may ship older mpv. Upgrade from a trusted source or use a Flatpak release containing mpv 0.42+. Older published bundles are unchanged.

Linux: Quick installer (1 command)

Downloads the latest GitHub release, verifies its SHA-256 checksum against checksums.txt, and installs the Arch package (via pacman -U) on Arch-based systems or the Flatpak bundle (--user) on other distributions—without needing Flathub or AUR.

curl -fsSL https://youtfast.pages.dev/install.sh | sh

Optional flags: --method flatpak, --method arch, --uninstall

Linux: Flatpak (any distribution)

Recommended for your system

Recommended for Linux. The bundle already contains libmpv, yt-dlp and Deno. You only need Flatpak; most distributions ship it, otherwise follow Flatpak’s setup page.

Flatpak setup for your distribution ↗

  1. Open a terminal.
  2. Download the bundle and its checksums, and check the download. The last line must end in OK.
curl -LO https://github.com/bcosta19/youtfast/releases/download/v{{VERSION}}/youtfast-v{{VERSION}}-x86_64.flatpak
curl -LO https://github.com/bcosta19/youtfast/releases/download/v{{VERSION}}/checksums.txt
sha256sum -c --ignore-missing checksums.txt
  1. Install it for your user. The first time, Flatpak also downloads the runtime it needs; answer y when asked.
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./youtfast-v{{VERSION}}-x86_64.flatpak
  1. Open YouTFast from the application menu, or run: flatpak run io.github.bcosta19.YouTFast
Update
Repeat the steps with the next release; there is no automatic update channel yet.
Remove
flatpak uninstall --user io.github.bcosta19.YouTFast

The Flatpak cannot read your browser’s profile: to sign in, choose a cookies.txt file in the app, or stay signed out.

Linux: Arch, Manjaro, EndeavourOS, CachyOS, Omarchy

A pacman package. pacman installs mpv, yt-dlp, Deno and every other library YouTFast needs. Releases containing the #84 fix require mpv 0.42+; older published packages do not enforce this. Check pacman -Q mpv and run sudo pacman -Syu if needed.

  1. Open a terminal, download the package and check it.
curl -LO https://github.com/bcosta19/youtfast/releases/download/v{{VERSION}}/youtfast-{{VERSION}}-1-x86_64.pkg.tar.zst
curl -LO https://github.com/bcosta19/youtfast/releases/download/v{{VERSION}}/checksums.txt
sha256sum -c --ignore-missing checksums.txt
  1. Install it:
sudo pacman -U ./youtfast-{{VERSION}}-1-x86_64.pkg.tar.zst
  1. Open YouTFast from the application menu, or run youtfast.
Update
Repeat the steps with the next release, and keep the system updated (sudo pacman -Syu) so yt-dlp stays current.
Remove
sudo pacman -R youtfast

Linux: Ubuntu, Debian, Linux Mint, Pop!_OS

For Ubuntu 24.04+, Debian 13+, Linux Mint 22+ or Pop!_OS 24.04+ without Flatpak. Older versions: use the Flatpak.

  1. Open a terminal and install the libraries YouTFast uses:
sudo apt-get update
sudo apt-get install libmpv2 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 \
  libgl1 libfontconfig1 pipx unzip curl
  1. Install the current yt-dlp and Deno for your user, in ~/.local/bin. The distribution’s yt-dlp package is too old to play YouTube videos.
pipx ensurepath
pipx install "yt-dlp[default]"
curl -fsSL https://deno.land/install.sh | DENO_INSTALL="$HOME/.local" sh -s -- -y --no-modify-path

If pipx ensurepath says it changed your PATH, log out and back in once, so programs opened from the menu find yt-dlp. Then yt-dlp --version and deno --version must both work in a new terminal.

  1. Download YouTFast, check it, and install the program, its icon and its menu entry for your user. The last command prints the version.
curl -LO https://github.com/bcosta19/youtfast/releases/download/v{{VERSION}}/youtfast-v{{VERSION}}-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/bcosta19/youtfast/releases/download/v{{VERSION}}/checksums.txt
sha256sum -c --ignore-missing checksums.txt
tar xzf youtfast-v{{VERSION}}-x86_64-unknown-linux-gnu.tar.gz
cd youtfast-v{{VERSION}}-x86_64-unknown-linux-gnu
install -Dm755 youtfast ~/.local/bin/youtfast
install -Dm644 packaging/icons/youtfast.svg ~/.local/share/icons/hicolor/scalable/apps/youtfast.svg
sed "s|^Exec=youtfast|Exec=$HOME/.local/bin/youtfast|" packaging/applications/youtfast.desktop \
  | install -Dm644 /dev/stdin ~/.local/share/applications/youtfast.desktop
~/.local/bin/youtfast --version
  1. Open YouTFast from the application menu, or run youtfast.
Update
YouTFast updates itself in Settings → About. Update yt-dlp with pipx upgrade yt-dlp when videos stop loading.
Remove
rm ~/.local/bin/youtfast ~/.local/share/applications/youtfast.desktop ~/.local/share/icons/hicolor/scalable/apps/youtfast.svg

Windows 10 and 11

Recommended for your system

For 64-bit Windows 10 or 11. The graphical setup (.exe) installs per-user without an administrator prompt and can install missing yt-dlp and Deno with Winget (App Installer).

  1. Download the Windows installer (.exe), or run the verified PowerShell command below:

Download installer (.exe)

irm https://youtfast.pages.dev/install.ps1 | iex
  1. When SmartScreen warns about apps without a publisher signature, choose More info and Run anyway. Follow the wizard; if it installs yt-dlp and Deno for the first time, sign out of Windows and back in.
  2. Prefer a portable folder instead of an installer? Install yt-dlp and Deno via winget, then extract the portable ZIP keeping all DLLs together:

Download portable ZIP (.zip) ↗

To check any Windows download first, run Get-FileHash in PowerShell and compare the Hash with its line in checksums.txt.

Update
YouTFast updates itself in Settings → About. Update yt-dlp with winget upgrade --id yt-dlp.yt-dlp when videos stop loading.
Remove
Uninstall YouTFast in Windows Settings → Apps (or delete the folder if using the portable ZIP).

macOS

Recommended for your system

For Macs with Apple Silicon (M1 or newer) on macOS 15 or newer; Intel Macs are not supported. You also need Homebrew.

Homebrew ↗ Homebrew tap ↗

  1. Option A (recommended): install YouTFast, yt-dlp and Deno in one command via the personal Homebrew tap:
brew install --cask bcosta19/tap/youtfast
  1. Option B (manual ZIP): install yt-dlp and Deno first, then download YouTFast:
brew install yt-dlp deno

Download for macOS (.zip)

  1. Double-click the ZIP to unpack it, then drag YouTFast.app into Applications.
  2. Open YouTFast. With the manual ZIP, macOS refuses it the first time because Apple has not notarized it: click Done, open System Settings → Privacy & Security, click Open Anyway next to the YouTFast message and confirm with your password. (The Homebrew tap clears quarantine automatically.)

To check the download first, run shasum -a 256 on the ZIP in Terminal and compare the result with its line in checksums.txt.

Update
YouTFast updates itself in Settings → About. Update yt-dlp with brew upgrade yt-dlp when videos stop loading.
Remove
Drag YouTFast.app from Applications to the Trash.

Your data and troubleshooting

Removing YouTFast keeps your library and settings. For a clean removal also delete: ~/.local/share/youtfast and ~/.config/youtfast (Arch package or native archive), ~/.var/app/io.github.bcosta19.YouTFast (Flatpak), %APPDATA%\youtfast (Windows), ~/Library/Application Support/youtfast (macOS). Sign out in the app first: the session lives in the system’s credential store.

  • Videos never start: update yt-dlp, then check that yt-dlp --version and deno --version work in a new terminal.
  • Intermittent “Could not play this video. The player did not identify the cause. Try reopening the video.”: check the installed libmpv package version. Upgrade to 0.42+ with Lua, or use a Flatpak release containing it. Older hooks can open streams too early and receive HTTP 403; reopening after a few seconds is only a workaround. If it persists on 0.42+, report it.
  • libmpv.so.2 or GLIBC_2.39 not found on Linux: your system is missing libmpv or is too old for the native archive; use the Flatpak.
  • youtfast: command not found: use the menu entry, or log out and back in so ~/.local/bin is on your PATH.
