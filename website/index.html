Watch YouTube on your computer, lighter and faster.

YouTFast is a free app that plays YouTube videos in its own window, without a web browser. Keep your subscriptions, history and Watch later list on your computer, with or without an account.

What you can do with it.

Everything below is in the current release.

Watch in its own window

Full screen or theater mode, with hardware video decoding where your computer supports it. No browser tab needed.

Your library stays with you

Subscriptions, history and Watch later are saved on this computer, without an account. Google Takeout files can be imported.

Pick up where you left off

YouTFast remembers how far you watched each video and resumes from that point.

Keep watching while you work

A small mini player floats in a corner. Audio-only mode (Shift+A) plays just the sound to save data and battery.

Captions, chapters and more

Captions and chapters, plus optional transcripts and timeline previews. SponsorBlock, to skip sponsored segments, is optional and off by default.

Made for the desktop

Keyboard shortcuts, media keys, light and dark themes, and six interface languages: English, Portuguese, Spanish, French, German and Italian.

Is YouTFast for you?

Choose YouTFast if…

  • you want to watch YouTube on a Linux, Windows or Apple Silicon Mac computer without a web browser.
  • you want subscriptions, history and Watch later kept on your computer, with no account.
  • you are fine with a young project from a single maintainer, with rough edges.

Prefer something else if…

  • you need a phone or tablet app: YouTFast is for desktop computers only.
  • you need live chat or downloading videos: they are not included.

Detailed instructions
  1. Install yt-dlp and Deno first.
  2. Download the ZIP, right-click it and choose Extract All.
  3. Open youtfast.exe in the extracted folder.

Windows SmartScreen may warn about new apps without a publisher signature, and YouTFast has none. If you trust the download, choose More info, then Run anyway. You can first compare the file's SHA-256 with checksums.txt.

Common questions.

Is it free?

Yes. YouTFast is free software under the GPL-3.0-only license, and its source code is public on GitHub.

Is it safe? What is open source?

Open source means all of the application's code is public, so anyone can read it. It has no telemetry and no YouTFast server, and each release publishes a checksums.txt. A checksum only detects a corrupted or incomplete download; it cannot show that a release was not tampered with. Release builds come from the public GitHub Actions release workflow, so you can read how they are made. The Windows build has no publisher signature and the macOS build is not notarized, so those systems may ask you to confirm before opening it.

Release workflow ↗

Do I need a Google account?

No. You can search, watch and keep a library on this computer without one. If you do sign in, we suggest using a secondary Google account: YouTube has no official sign-in for apps like this one, and Google may treat the session as automated access, which could ask the account to verify itself, sign it out or suspend it.

How does sign-in work?

YouTFast does not ask for your password. It uses the YouTube session your browser already has, read from the browser's login or from a cookies.txt file you export. The session is stored only in your system's credential store, never in a file or a log.

Will it break when YouTube changes?

It can. YouTFast is an unofficial client, and a YouTube change can stop videos from loading. Often the fix is updating yt-dlp (the Flatpak bundles it, so install the next bundle). If it still fails, please open an issue.

How do I uninstall it?

Flatpak: run flatpak uninstall --user io.github.bcosta19.YouTFast. Arch package: remove youtfast with pacman. Windows and macOS have no installer, so delete the folder or app you extracted. Your library and settings stay in your user folders until you delete them.

What if Windows shows a warning?

The Windows build has no publisher signature, so SmartScreen may warn about it. You can compare the file's SHA-256 with checksums.txt on the release page. If it matches and you trust the source, choose More info, then Run anyway.

Is this an official YouTube app?

No. YouTFast is independent and unaffiliated with YouTube or Google.

Where can I get help?

Open an issue on GitHub with your version, system and what happened. Portuguese is welcome.

How it works.

For the curious and for developers: where the data comes from, what stays on your computer and what can break.

Where the data comes from

Feeds, search, channels and account data come from YouTube's InnerTube interface through the RustyPipe library. yt-dlp finds the video streams and libmpv plays them. The interface is Rust with egui.

What stays on your computer

There is no YouTFast server and no telemetry. Your library and settings are files in your user folders, and the optional account session lives in your system's credential store.

Network calls it makes

To YouTube, for data, thumbnails and streams; to SponsorBlock, only if you turn it on; and to GitHub Releases, to check for new versions.

When YouTube changes

YouTube can change its responses and break extraction. Native packages keep yt-dlp separate so you can update it on its own; the Flatpak bundles it, so you install the next bundle. Fixes to YouTFast itself arrive in new releases.

Accounts

YouTube offers no sign-in for apps like this, so YouTFast reuses a session from your browser's login or a cookies.txt file. Google may treat that as automated access, so a secondary account is the safe choice.
