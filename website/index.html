A few things to know.

Do I need a Google account?

No. Start signed out and keep a local library. Optional account integration uses the system credential store. It is unofficial and can trigger Google verification or sign-out; read the account guide before connecting.

Read about accounts ↗
Is this an official YouTube app?

No. YouTFast is an independent, unofficial client, unaffiliated with YouTube or Google. YouTube can change its services at any time, and using an unofficial client may conflict with its terms.

How do updates work?

Native packages include an updater in Settings → About. Downloads are checked against the release's SHA-256 checksums. Package availability and update paths vary by platform; see the installation guide for details.

Can I build it myself?

Yes. The repository includes the source, locked dependencies, and build instructions. You'll need the pinned Rust toolchain, system libraries, libmpv, and current playback extraction tools.
