# YouTFast 0.2.0

This release adds more interface languages, opens channel links directly and
keeps playback visible with an optional miniplayer while scrolling. It also
improves startup, thumbnail loading and compatibility with YouTube's channel
pages.

**Release candidate.** Packages and their corresponding sources must pass the
hosted Release workflow and review before publication. Interactive Windows and
macOS qualification remains open ([Windows #5](https://github.com/bcosta19/youtfast/issues/5),
[macOS #6](https://github.com/bcosta19/youtfast/issues/6)); automated tests and
startup checks do not establish playback or credential-store support.

## Included

- Spanish, French, German and Italian interface languages alongside English
  and Brazilian Portuguese, selectable in Settings.
- Channel links using `/@handle`, `/channel/UC…`, `/c/name` and `/user/name`
  open channel pages. Switching to About during initial loading preserves the
  channel's resolved identity, header and Subscribe button.
- An optional miniplayer when the inline video scrolls above the watch page.
  Returning to the video reveals the inline player again.
- Video rendering preserves its aspect ratio and stays clipped below the
  toolbar while scrolling.
- The window opens while system fonts are found in the background. Cached
  thumbnails display without waiting for the download queue, and downloads
  reuse network connections.
- Playback loads only mpv's extraction hook among its bundled scripts,
  reducing background threads and memory use.
- Failed visitor-data requests, panics and overdue listing loads produce a
  controlled error that can be retried instead of closing or stalling the app.
- Updated YouTube channel sorting, Shorts, playlists and podcast handling,
  with corrected subscriber/video counts and synthetic regression tests.

Existing settings and the local library remain supported. The scrolling
miniplayer is off by default; enable it in Playback settings. No manual data
migration is required.

## Candidate packages

The hosted workflow prepares Linux x86_64 archives, a Flatpak bundle and its
sources, an Arch package and recipe, Windows x86_64 and macOS Apple Silicon
bundles, matching native sources, and Rust source with locked dependencies.
The final inventory must include `checksums.txt` covering all downloads.

The native Linux archive requires glibc 2.39+, system libmpv and current
yt-dlp/Deno. Windows and macOS bundles include libmpv but require current
yt-dlp/Deno. The Flatpak bundles its extraction and playback tools and uses
the Freedesktop 25.08 runtime. macOS requires version 15+ on Apple Silicon.

Installation and platform requirements are in the
[distribution guide](https://github.com/bcosta19/youtfast/blob/v0.2.0/docs/distribution.md).
Retrieve candidate artifacts from the Release workflow run once its builds
finish. Published downloads follow package and source review.

## Not included

- Flathub or AUR listings, a signed pacman repository or automatic updates.
- Linux ARM64, Intel/universal macOS, Windows ARM64, AppImage, DEB/RPM,
  MSI/MSIX installers or a DMG.
- Windows publisher signing, macOS Developer ID signing or notarization.
- Live chat, downloads or official Google OAuth sign-in.
- Completed interactive Windows/macOS QA or native-source qualification.

## Known limitations

- YouTFast is an unofficial client. YouTube changes can break extraction;
  keep yt-dlp current. Playback stays signed out by default.
- Windows Credential Manager can reject sessions larger than its 2560-byte
  secret limit. Native account behavior requires interactive validation.
- Browser-session import needs Python with the `yt_dlp` module. Flatpak
  cannot read host browser profiles; use cookies.txt import there.
- Signed-in playback retry is available only for browser-imported accounts.
- Flatpak is distributed as a bundle without an update remote. Install the
  next bundle to update.
