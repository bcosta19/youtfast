# YouTFast 0.7.0

A desktop ergonomics, packaging, and InnerTube independence release. YouTFast now
queries YouTube directly through its in-tree InnerTube client, redesigns the
notifications popup, adds a top-bar refresh button, and introduces a per-user
Windows graphical setup installer alongside verified one-command install scripts
for Linux and Windows.

## Included

- **In-tree InnerTube client (#91)**: YouTube browsing, search, channel tabs,
  watch pages, comments, playlists, and signed-in actions run directly through
  `crates/youtfast-youtube/src/innertube/` without the RustyPipe fork. Session
  cookies remain in memory and the platform credential store only, with no
  client cache written to disk.
- **Notifications and navigation (#92, #93)**: redesigned notifications popup
  and empty state, plus a top-bar Refresh button beside Back and Forward
  (moving the Refresh shortcut to Ctrl/Cmd+R).
- **Windows graphical setup installer (.exe)**: new per-user NSIS setup wizard
  (`youtfast-v0.7.0-x86_64-windows-setup.exe`) installing into
  `%LOCALAPPDATA%\Programs\YouTFast` (keeping in-app auto-updates writable), with
  Start Menu/Desktop shortcuts, Windows Uninstall entry, and optional `winget`
  installation of missing `yt-dlp` and `Deno`. The portable ZIP remains
  available.
- **One-command verified installers**: `https://youtfast.pages.dev/install.sh`
  (auto-detects Arch `pacman -U` or Flatpak `--user`, or installs native
  `.tar.gz`) and `https://youtfast.pages.dev/install.ps1` (Windows), checking
  `checksums.txt` SHA-256 digests before installing.
- **Channel manifests (`channels.tar.gz`)**: updated to emit multi-file
  `microsoft/winget-pkgs` 1.6.0 manifests for the NSIS installer alongside the
  Homebrew Cask for a personal tap.
- **InnerTube parsing fixes**: preserves comment continuations, pinned-thread
  indicators, image attachments, voice-reply transcripts, and spelled-out
  Shorts view-count multipliers.

Existing settings, local libraries and signed-in accounts remain supported;
no file or setting changes format.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64 (per-user NSIS `.exe`
installer and portable `.zip`); macOS 15+ Apple Silicon; locked Rust sources,
matching native sources, notices, channel manifests and SHA-256 checksums.

Native Linux requires glibc 2.39+, **system libmpv 0.42+ with Lua**, and current
yt-dlp/Deno. Windows/macOS bundle libmpv but still require external yt-dlp and
Deno. Flatpak includes its playback and extraction tools. Google Cast requires
`catt` installed separately. Channel manifests are submission inputs, not
evidence of publication in a package store.

## Not included

- New product features beyond those listed above: see [ROADMAP.md](https://github.com/bcosta19/youtfast/blob/v0.7.0/ROADMAP.md).
- Choosing an installed interface font on Windows and macOS.
- Bundled `yt-dlp`/`Deno` inside Windows release binaries (#56) or a bundled
  `catt` helper.
- Flathub or AUR store publication, Winget/Homebrew external repository
  acceptance, Windows publisher signing (Authenticode) or macOS notarization.
- Intel Macs, Windows ARM64, Linux ARM64, downloads or live chat.
- Completed interactive Windows/macOS platform qualification.

## Known limitations

- Older native libmpv versions remain unsupported even if the executable starts.
  Updating YouTFast does not update a native Linux system's libmpv; use a trusted
  current package or a Flatpak release containing the updated playback stack.
- YouTube changes can break extraction; keep yt-dlp current. Playback is
  signed out by default.
- Casting has not been qualified on physical Chromecast/Google TV devices or
  native Windows/macOS, and Flatpak TV discovery remains unqualified.
- Windows Credential Manager may reject sessions over its 2560-byte limit.
  Browser-session import additionally needs Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Windows/macOS automated builds and headless tests do not establish
  interactive playback, graphics or credential-store coverage. Platform QA
  remains tracked in [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
