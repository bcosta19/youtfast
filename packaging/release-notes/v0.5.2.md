# YouTFast 0.5.2

A patch release: the watch page fits the player to each video, and timestamps
and web links in comments and descriptions work when clicked.

## Included

- **Player sized to the video**: the watch page player takes the video's own
  aspect ratio (16:9, 4:3, 21:9 and other landscape shapes) instead of leaving
  black bars inside a fixed pane; square and portrait videos keep YouTube's
  16:9 box. Up next takes the remaining width, up to 600 px, and theater mode
  uses the full content width with the title and channel row above the fold.
  Shorts, the mini player and fullscreen are unchanged.
- **Comment timestamps** seek within the current video instead of reopening
  it, including `0:00`. Timestamps and links respond across their visible
  text, not only below the letters.
- **Web links** in descriptions, comments and replies open in the default
  browser when left-clicked; right-click Copy remains available.
- **Dependency updates**: tokio 1.54.1 and rustls-platform-verifier 0.7.1, which
  checks YouTube's certificates through the operating system.

Existing settings, local libraries and signed-in accounts remain supported; no
file or setting changes format.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64; macOS 15+ Apple Silicon;
locked Rust sources, matching native sources, notices, channel manifests and
SHA-256 checksums.

Native Linux requires glibc 2.39+, system libmpv and current yt-dlp/Deno.
Windows/macOS bundle libmpv but still require external yt-dlp and Deno.
Flatpak includes its playback and extraction tools. Google Cast requires `catt`
installed separately. Channel manifests are submission inputs, not evidence of
publication in a package store.

## Not included

- New features: see [ROADMAP.md](https://github.com/bcosta19/youtfast/blob/v0.5.2/ROADMAP.md).
- Bundled Windows yt-dlp/Deno (issue #56) and a bundled `catt` helper.
- Flathub, AUR, Winget or Homebrew store submission, native installers,
  Windows publisher signing or macOS notarization.
- Intel Macs, Windows ARM64, Linux ARM64, downloads or live chat.
- Completed interactive Windows/macOS platform qualification.

## Known limitations

- YouTube changes can break extraction; keep yt-dlp current. Playback is
  signed out by default.
- Casting has not been qualified on physical Chromecast/Google TV devices or on
  native Windows/macOS, and the Flatpak sandbox has not been qualified for TV
  discovery.
- Windows Credential Manager may reject sessions over its 2560-byte limit.
  Browser-session import additionally needs Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Windows/macOS automated builds and headless tests do not establish
  interactive playback, graphics or credential-store coverage. Platform QA
  remains tracked in [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
