# YouTFast 0.1.0

**YouTube, native and fast.** The first release of a small desktop YouTube
client built with Rust, egui and libmpv: in-window playback with hardware
decoding, a local library that works without an account, and optional sign-in.
No browser engine, no telemetry and no YouTFast-operated backend.

![YouTFast showing search results, full screen](https://raw.githubusercontent.com/bcosta19/youtfast/v0.1.0/assets/screenshots/search.png)

> [!NOTE]
> **Pre-release, and help is welcome.** Every package below was built and tested
> headlessly on GitHub-hosted runners, but YouTFast is young and has rough
> edges. Nobody has tried the Windows ([#5](https://github.com/bcosta19/youtfast/issues/5))
> or macOS ([#6](https://github.com/bcosta19/youtfast/issues/6)) builds on a
> real machine yet; please [report what you find](https://github.com/bcosta19/youtfast/issues/new/choose).

On the same search results page, full screen and signed out, YouTFast used
**161 MiB and 0% CPU** while an Electron app showing youtube.com used 658 MiB
and 18% of a core ([benchmarks](https://github.com/bcosta19/youtfast/blob/v0.1.0/docs/benchmarks.md)).

### Quick start

```sh
# Linux (Flatpak)
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./youtfast-v0.1.0-x86_64.flatpak
flatpak run io.github.bcosta19.YouTFast

# Arch Linux
sudo pacman -U ./youtfast-0.1.0-1-x86_64.pkg.tar.zst
```

On **Windows**, extract the whole ZIP and run `youtfast.exe`. On **macOS**,
copy `YouTFast.app` to Applications and open it from Finder. The app is ad-hoc signed, so macOS may ask
you to approve it in *System Settings → Privacy & Security*. Install a current
[yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) and
[Deno](https://docs.deno.com/runtime/getting_started/installation/) on both.

Verify a download with `sha256sum --check --ignore-missing checksums.txt`.
See the [installation guide](https://github.com/bcosta19/youtfast/blob/v0.1.0/docs/distribution.md)
for runtime requirements and the [user guide](https://github.com/bcosta19/youtfast/blob/v0.1.0/docs/user-guide.md)
for controls, library and accounts.

## Included

- **Playback:** libmpv video with hardware decoding where available, full
  screen, theater mode, a movable mini player, captions, chapters, queue
  editing, keyboard shortcuts and desktop media controls.
- **Browsing:** search for videos, channels and playlists with filters,
  paginated feeds, channel tabs, Shorts and back/forward navigation.
- **Watch page:** comments with image/GIF attachments, optional transcripts,
  timeline previews and SponsorBlock.
- **Library without an account:** subscriptions, Watch later, history with
  resume, Google Takeout import and new-upload notifications.
- **Optional accounts:** named sessions in the system credential store, ratings
  and playlist edits, with rollback when YouTube refuses a change.
- **Interface:** English and Brazilian Portuguese, light and dark themes,
  palettes and Omarchy integration on native Linux installs.
- **Reliability and privacy:** ordered saves that preserve unreadable files,
  bounded downloads and decoding, clear playback errors and redacted, rotating
  local diagnostic logs.

## Not included

- Flathub and AUR listings, a signed pacman repository and automatic updates.
- Linux ARM64, Intel/universal macOS, ARM Windows, AppImage, DEB/RPM,
  MSI/MSIX installers or a DMG.
- Windows publisher signing and macOS notarization.
- Live chat, downloads and official Google OAuth sign-in.

Planned work lives in the [roadmap](https://github.com/bcosta19/youtfast/blob/v0.1.0/ROADMAP.md);
no dates are promised.

## Known limitations

- YouTFast is an unofficial client, not affiliated with YouTube or Google.
  YouTube changes can break extraction until yt-dlp or RustyPipe catch up;
  keep yt-dlp current. Signing in is optional and can trigger verification or
  account restrictions, so playback stays signed out by default.
- Windows Credential Manager may reject very large sessions.
- Importing a browser session needs `python3` with the `yt_dlp` module; the
  Flatpak cannot read host browser profiles, so use a cookies.txt file there.
- Signed-in playback retry works only for browser-imported accounts.
- The Flatpak is a single x86_64 bundle without an update remote; install the
  next bundle to update.
