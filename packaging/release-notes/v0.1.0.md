# YouTFast 0.1.0

First release of a small native YouTube desktop client, with in-window playback,
a device library and optional accounts. These notes describe the candidate;
publication still requires the privacy, source and platform QA gates.

## Downloads

- **Linux x86_64:** native archive (Ubuntu 24.04/glibc 2.39+ and system libmpv),
  or Flatpak with its packaged playback/extraction tools.
- **Windows x86_64:** ZIP with libmpv and imported DLLs. Install current yt-dlp
  and Deno separately on PATH; this is not an installer or publisher-signed app.
- **macOS 15+ Apple Silicon:** ZIP with an app and bundled libmpv/dylibs. Install
  current yt-dlp and Deno separately. Ad-hoc signing is not Developer ID signing
  or notarization; macOS may require trusted-app approval.
- **Arch:** pacman package for local `pacman -U` installation and source PKGBUILD
  with `.SRCINFO` and an exact checksum, after the hosted Arch build passes.
  AUR submission is separate; no `pacman -S` repository is claimed.
- **Sources/checksums:** locked Rust dependencies, Flatpak sources and SHA-256
  digests. Matching Windows/macOS native sources must also accompany the final
  public binaries; their inventories alone are not source distributions.

See [distribution and installation](https://github.com/bcosta19/youtfast/blob/v0.1.0/docs/distribution.md)
for architecture/runtime requirements and [the release checklist](https://github.com/bcosta19/youtfast/blob/v0.1.0/docs/public-release-checklist.md)
for publication gates. Do not advertise downloads as available before the draft
is approved and published.

## Included

- Native libmpv video, full screen, captions, chapters, theater/mini player,
  queue editing, keyboard shortcuts and desktop media controls.
- Search for videos/channels/playlists, filters, paginated feeds, channel tabs,
  Shorts and back/forward navigation.
- Comments and image/GIF attachments; optional transcript, timeline previews
  and SponsorBlock integration.
- Local subscriptions, Watch later, history/resume, bounded Takeout imports and
  new-upload notifications.
- Named accounts through the system credential store, account ratings and
  playlist edits; stale account responses and refused writes are handled.
- English/Brazilian Portuguese, light/dark themes, palettes, native Linux
  Omarchy integration and synthetic offline demo fixtures.
- Ordered saves, preservation of unreadable files, bounded downloads/decoding,
  controlled playback errors and redacted rotating local diagnostics.

## Not included

- Flathub/AUR publication, signed pacman repository and automatic app updates.
- Linux ARM64, macOS Intel/universal binaries, AppImage, DEB/RPM, Windows
  MSI/MSIX, macOS DMG, publisher signing or notarization.
- Live chat, downloads and official Google OAuth sign-in.
- Host browser-profile or automatic host-theme access from the Flatpak sandbox.

Deferred work is tracked in [ROADMAP.md](https://github.com/bcosta19/youtfast/blob/v0.1.0/ROADMAP.md);
no next-version delivery date is promised.

## Known limitations

- Early-stage unofficial client, unaffiliated with YouTube/Google. Upstream
  changes can break extraction/authenticated requests. Signed-out playback is
  the default; an account session can trigger verification or suspension.
- Passing compilation, dependency checks and `--version` is not interactive
  playback/account validation. Record actual qualification before publication.
- Optional browser import needs `python3` and the `yt_dlp` module in addition to
  the executable. Windows Credential Manager may reject oversized sessions.
- Signed-in playback retry is available only for browser-source accounts;
  cookies.txt accounts do not have that fallback.
- Flatpak is currently an x86_64 bundle without an application update remote;
  the Freedesktop runtime is downloaded separately.
