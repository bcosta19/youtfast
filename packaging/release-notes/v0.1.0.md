YouTFast 0.1.0 is the first release of a small native YouTube desktop client,
with in-window playback, a local library and optional accounts.

**Downloads:** Linux x86_64 archive, Flatpak bundle, corresponding source and
SHA-256 checksums are attached to this release. The native archive requires
Ubuntu 24.04-compatible libraries and glibc 2.39 or newer; use Flatpak on other
compatible distributions. This release remains private to invited collaborators.

![YouTFast with a fresh, signed-out profile](https://github.com/bcosta19/youtfast/releases/download/v0.1.0/youtfast-v0.1.0-linux.png)

## New

- **Native video playback:** search, watch-page details and comments, a mini
  player, captions, chapters, keyboard controls and desktop media controls.
- **Your local library:** subscriptions, Watch later, history/resume positions,
  bounded Google Takeout imports and new-upload alerts.
- **Optional accounts:** named accounts use the platform credential store;
  sessions are not stored in the library or settings.
- **Contributor-ready checks:** documented setup and contribution policy,
  read-only pull-request CI, native platform checks and versioned release assets.
- **Linux Flatpak bundle:** runtime dependencies are included in a restricted
  sandbox, without granting access to host browser profiles.

## Fixed

- **Account changes stay isolated:** old responses and private lists cannot
  repopulate a new account, including after expiration or login failure.
- **Local changes stay safe:** unreadable files are preserved, final saves are
  ordered, and imports cannot replace newer edits.
- **Failed requests can recover:** comments and alerts allow retry; keyring
  timeouts cannot stack overlapping credential-store calls.
- **Large lists do less work:** viewport-aware rendering and shared, bounded
  thumbnail downloads reduce unnecessary layout and duplicate requests.
- **Diagnostics remain private:** controlled messages replace account names,
  video identifiers, URLs and raw external errors, including verbose logging.

## Known limitations

- This is an early-stage unofficial client, not affiliated with YouTube or Google.
  YouTube changes can break extraction and authenticated requests.
- Windows/macOS installers, interactive platform validation, code signing and
  notarization are not part of this release. Automated compilation is not proof
  of working playback or account login.
- The Flatpak is a downloadable bundle, not a Flathub listing or an update remote.
  Host browser sign-in and automatic host theme access are intentionally absent.
- Private repository access is required for releases and contributions. Mandatory
  branch protection is unavailable on the current private repository plan.
- Cookies identify a Google session. Signing in through an unofficial client can
  cause verification, sign-out or suspension; signed-out playback is the default.
