# YouTFast 0.3.0

This release adds **Settings → About** with system update notifications and
SHA-256-verified automatic minor/patch updates, a configurable playback buffer,
audio-only mode, History sync options, and distribution channel manifest
generation (Flathub, Winget and Homebrew Cask). It also refines page scrolling,
keyboard navigation, the compact frameless mini player, and the History and
channel views.

**Release candidate.** Packages and their corresponding sources must pass the
hosted Release workflow and review before publication. Interactive Windows and
macOS qualification remains open ([Windows #5](https://github.com/bcosta19/youtfast/issues/5),
[macOS #6](https://github.com/bcosta19/youtfast/issues/6)); automated tests and
startup checks do not establish playback or credential-store support.

## Included

- **About section and built-in updater (`Settings → About`)**: shows the
  installed version and bundled changelog, checks GitHub Releases for new
  stable versions with optional system desktop notifications, supports automatic
  SHA-256-verified updates for minor (`0.x.0`) and patch (`0.0.x`) releases with
  persisted changelog notes of what changed, and requires manual 1-click
  confirmation for major (`x.0.0`) releases.
- **Distribution channel manifest generator (`packaging/channels.py`)**:
  produces a Flathub source-build manifest (`io.github.bcosta19.YouTFast.json`),
  a Windows Winget singleton manifest (`bcosta19.YouTFast.yaml`), and a macOS
  Homebrew Cask (`youtfast.rb`) with exact release asset SHA-256 digests,
  packaged in `youtfast-v0.3.0-channels.tar.gz`.
- **Configurable video buffer (`Settings → Playback → Video buffer`)**: defaults
  to mpv's standard 150 MiB ahead / 50 MiB behind for smoother playback on
  unstable connections and instant seeking, with a compact 50 MiB / 20 MiB
  option for lower RAM (~200 MB) and data usage.
- **Audio-only mode**: stream and decode only the audio track (`ba/b` and
  `vid=no`) for the current video via the player Quality menu or `Shift+A`,
  reducing bandwidth and CPU/GPU usage during background listening.
- **History sync (`Settings → History`)**: keep account and device history
  separate, merge them in YouTFast with local resume positions, or also report
  started playback (after two seconds of active play) to the signed-in account's
  YouTube history.
- **Compact frameless mini player**: simplified to a rounded 16:9 video box in
  the bottom-right corner without an outer window title bar or bottom metadata
  bar.
- **Faster page scrolling and keyboard navigation**: mouse wheel and touchpad
  scrolling use `fastframe-scroll` (120 pt wheel steps and touchpad momentum
  glide); `↑` and `↓` outside the player scroll the active page vertically while
  `j` and `k` move item selection; channel pages scroll from anywhere on the
  view.
- **Sidebar and UI polish**: the sidebar toggle (`b` or top-bar button)
  overrides the automatic rail on watch and narrow layouts on its first press;
  History row controls stay aligned with readable contrast; channel banners crop
  without stretching.

Existing settings and the local library remain supported without manual
migration.

## Candidate packages

The hosted workflow prepares Linux x86_64 archives, a Flatpak bundle and its
sources, an Arch package and recipe, Windows x86_64 and macOS Apple Silicon
bundles, matching native sources, Rust source with locked dependencies, and
rendered distribution channel manifests (`channels.tar.gz`). The final
inventory must include `checksums.txt` covering all downloads.

The native Linux archive requires glibc 2.39+, system libmpv and current
yt-dlp/Deno. The Windows bundle includes libmpv, `yt-dlp.exe` and `deno.exe`,
so nothing else needs installing. The macOS bundle includes libmpv but requires
current yt-dlp/Deno. The Flatpak bundles its extraction and playback tools and uses
the Freedesktop 25.08 runtime. macOS requires version 15+ on Apple Silicon.

Installation and platform requirements are in the
[distribution guide](https://github.com/bcosta19/youtfast/blob/v0.3.0/docs/distribution.md).
Retrieve candidate artifacts from the Release workflow run once its builds
finish. Published downloads follow package and source review.

## Not included

- Public Flathub, AUR, Winget or Homebrew tap publication, or a signed pacman
  repository (manifests are generated in `channels.tar.gz` for submission).
- Linux ARM64, Intel/universal macOS, Windows ARM64, AppImage, DEB/RPM,
  MSI/MSIX installers or a DMG.
- Windows publisher signing, macOS Developer ID signing or notarization.
- Live chat, downloads or official Google OAuth sign-in.
- Completed interactive Windows/macOS QA or native-source qualification.

## Known limitations

- YouTFast is an unofficial client. YouTube changes can break extraction;
  keep yt-dlp current. Playback stays signed out by default.
- Windows Credential Manager can reject sessions larger than its 2560-byte
  secret limit. Native account behavior requires interactive validation.
- Browser-session import needs Python with the `yt_dlp` module. Flatpak
  cannot read host browser profiles; use cookies.txt import there.
- Signed-in playback retry is available only for browser-imported accounts.
- Flatpak is distributed as a bundle without an update remote until a Flathub
  listing is published. Install the next bundle to update.
