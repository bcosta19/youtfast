# YouTFast 0.4.0

System fonts, a customizable sidebar and faster rendering of large lists,
with keyboard, account and playback reliability fixes.

## Included

- **System interface fonts** by default, with Inter available in Settings →
  Appearance. Switching applies immediately. If the system font cannot load,
  Inter is used and a prefilled issue form is available for reporting it.
- **Customizable sidebar**: hide and reorder buttons, or restore the defaults.
  Account and Settings stay visible. Number shortcuts follow the visible order.
- **Cheaper redraws** on History, Home, Notifications and comments. History
  caches and virtualizes its rows; expired thumbnail URI entries are released.
  Audio-only playback polls position instead of observing every position tick.
- **Keyboard and layout fixes**: visible focus, reachable player controls,
  corrected double-click behavior, account rename editing and narrow layouts.
- **Account reliability**: retry temporary session failures, serialize rating
  and playlist writes, and discard stale account and search results.
- **Playback and imports**: queue changes update autoplay; late SponsorBlock
  results are discarded when disabled; multiline Takeout subscriptions import.
- **Windows fixes**: platform certificate verification, an executable icon and
  a clearer error when OpenGL is unavailable.
- **English/Portuguese project website** with direct release downloads,
  installation guidance, a FAQ, compact fonts and reduced-motion support.

Existing settings and local libraries remain supported. Existing settings now
default to the system font; the Inter option restores the previous face.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64; macOS 15+ Apple Silicon;
locked Rust sources, matching native sources, notices, channel manifests and
SHA-256 checksums.

Native Linux requires glibc 2.39+, system libmpv and current yt-dlp/Deno.
Windows/macOS bundle libmpv but still require external yt-dlp and Deno.
Flatpak includes its playback and extraction tools. Channel manifests are
submission inputs, not evidence of publication in a package store.

## Not included

- Cast to TV (draft PR #50) and bundled Windows yt-dlp/Deno (issue #56).
- Flathub, AUR, Winget or Homebrew store submission, native installers,
  Windows publisher signing or macOS notarization.
- Intel Macs, Windows ARM64, Linux ARM64, downloads or live chat.
- Completed interactive Windows/macOS platform qualification.

## Known limitations

- YouTube changes can break extraction; keep yt-dlp current. Playback is
  signed out by default.
- Windows Credential Manager may reject sessions over its 2560-byte limit.
  Browser-session import additionally needs Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Windows/macOS automated builds and headless tests do not establish
  interactive playback, graphics or credential-store coverage. Platform QA
  remains tracked in [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
