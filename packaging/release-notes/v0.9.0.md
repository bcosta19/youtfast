# YouTFast 0.9.0

Matches in-app updates to each supported installation method, hardens self-update
replacement on Windows and Linux, and adds translated README, installation, and
user guides in five languages.

## Included

- **Installation-method-matched in-app updates**: detects `LinuxNative`,
  `ArchPacman`, `WindowsSetup`, `WindowsPortable`, `MacosBundle`, `Flatpak`, and
  `ManualOnly` installs, fetches the matching release asset and SHA-256
  checksum, runs periodic 12-hour release checks when notifications or auto-updates
  are enabled, and adds one-click **Restart now** actions in notifications and
  **Settings → About**.
- **Arch, Windows, and Flatpak flows**: Arch `pacman` installs update on click
  via `pkexec pacman -U` (never unattended in the background), Windows setup and
  portable installs stage verified updates and apply them cleanly on exit or
  restart, and sandboxed Flatpak installs notify and provide one-click update
  command copy.
- **Self-update safety fixes**: Windows portable updates use
  `native-dependencies.json` to preserve unrelated DLLs and legacy installs
  without a manifest, preserve renamed executables across backup, replacement,
  rollback, and relaunch, refuse self-updates on `mbx` development-cache
  binaries, and verify Linux native binaries beside the install target before
  atomic replacement (avoiding `noexec` cache failures).
- **Translated documentation**: README, user guide, and installation guide
  translated into Brazilian Portuguese, Spanish, French, German, and Italian,
  with a language switcher and packaging verification tests.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64 installer and portable
ZIP; macOS 15+ Apple Silicon; locked Rust sources, matching native sources,
notices, channel manifests and SHA-256 checksums. Native Linux needs glibc
2.39+, libmpv 0.42+ with Lua, and current yt-dlp and Deno; Windows and macOS
bundle libmpv but require yt-dlp and Deno separately. Flatpak includes its
playback and extraction tools.

## Not included

- Flathub or AUR publication, Winget/Homebrew external repository acceptance,
  Windows publisher signing (Authenticode) or macOS notarization.
- Intel macOS, Windows ARM64 or Linux ARM64 packages.
- Bundled yt-dlp and Deno in Windows packages, or a bundled Cast helper.

## Known limitations

- Windows and macOS automated builds do not establish interactive playback,
  graphics or credential-store coverage; platform QA remains tracked in
  [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
- Windows Credential Manager may reject sessions larger than 2560 bytes.
  Browser-session import additionally needs Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Casting remains unqualified on physical Chromecast and Google TV devices.
  YouTube changes can break playback extraction; keep yt-dlp current.
