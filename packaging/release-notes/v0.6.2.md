# YouTFast 0.6.2

A playback compatibility and security release. Flatpak now includes mpv 0.42.0
and libplacebo 7.387.0; native playback requires libmpv 0.42 or newer with Lua.
This candidate also includes the improvements in the unpublished 0.6.1 draft.
The existing 0.6.1 tag and draft are unchanged.

## Included

- **Intermittent playback failures (#84)**: mpv's yt-dlp hook now waits until
  streams become available instead of opening their URLs early and receiving
  HTTP 403. Flatpak upgrades its playback stack; Arch package dependencies and
  Windows/macOS bundle checks enforce the new libmpv baseline. Native Linux
  users must update their system libmpv separately.
- **Security**: the Flatpak mpv upgrade includes the upstream playlist-entry
  validation fix for CVE-2026-123095.
- **Installation guidance**: runtime requirements and troubleshooting explain
  the exact generic playback error, the libmpv 0.42+ requirement, and why merely
  reopening a video is only a temporary workaround. The website includes the
  same guidance in English and Brazilian Portuguese.
- **Liked videos and Watch later load faster**: both lists use the current
  YouTube layout directly instead of retrying an incompatible reader first
  (YT-8 in `docs/youtube-api-format.md`).
- **Failed videos**: a failed load no longer leaves the previous video's
  picture on screen or draws the title and description inside the player.
  The player stays black with the error; a spinner covers the first-frame wait.
- **Channel pages**: videos and their Up next entries show views, age and
  length again after a YouTube change (YT-7). A channel's videos retain their
  channel name and avatar, including after loading more.
- **Account page and keyboard shortcuts**: the Account page uses Settings-style
  cards with one account/profile per row. The shortcuts window has roomier
  margins and scrolls on short windows instead of clipping its contents.

Existing settings, local libraries and signed-in accounts remain supported;
no file or setting changes format.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64; macOS 15+ Apple Silicon;
locked Rust sources, matching native sources, notices, channel manifests and
SHA-256 checksums.

Native Linux requires glibc 2.39+, **system libmpv 0.42+ with Lua**, and current
yt-dlp/Deno. Windows/macOS bundle libmpv but still require external yt-dlp and
Deno. Flatpak includes its playback and extraction tools. Google Cast requires
`catt` installed separately. Channel manifests are submission inputs, not
evidence of publication in a package store.

## Not included

- New features: see [ROADMAP.md](https://github.com/bcosta19/youtfast/blob/v0.6.2/ROADMAP.md).
- Choosing an installed interface font on Windows and macOS.
- Bundled Windows yt-dlp/Deno (issue #56) and a bundled `catt` helper.
- Flathub, AUR, Winget or Homebrew store submission, native installers,
  Windows publisher signing or macOS notarization.
- Intel Macs, Windows ARM64, Linux ARM64, downloads or live chat.
- Completed interactive Windows/macOS platform qualification.

## Known limitations

- Older native libmpv versions remain unsupported even if the executable starts.
  Updating YouTFast does not update a native Linux system's libmpv; use a trusted
  current package or a Flatpak release containing the updated playback stack.
- YouTube changes can break extraction; keep yt-dlp current. Playback is
  signed out by default.
- Casting has not been qualified on physical Chromecast/Google TV devices or
  native Windows/macOS, and Flatpak TV discovery remains unqualified.
- Windows Credential Manager may reject sessions over its 2560-byte limit.
  Browser-session import additionally needs Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Windows/macOS automated builds and headless tests do not establish
  interactive playback, graphics or credential-store coverage. Platform QA
  remains tracked in [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
