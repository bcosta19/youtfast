# YouTFast 0.8.0

An interface architecture and library usability release. YouTFast 0.8.0 refreshes
the visual hierarchy across built-in light and dark palettes, turns
Subscriptions and channel search into metadata-rich channel cards with filtering
and sorting, fixes the Home Shorts shelf layout and 9:16 thumbnail crop, and
redesigns History, Watch later, Liked videos, and Playlists around responsive
grids, live filtering, and framed day sections.

## Included

- **Subscriptions and channel discovery cards**: multi-column responsive channel
  cards showing handles, subscriber and video counts, verified badges, bio
  snippets, local watch counts, and clickable latest-video previews, alongside
  inline search filtering and sorting (`Name`, `Recent`, `Most watched`), fed
  by in-memory InnerTube channel metadata enrichment.
- **Home Shorts shelf**: framed shelf with scroll and collapse controls,
  optional channel attribution on cards, corrected 9:16 thumbnail cropping
  without side bars or stretching, cleared titles away from the `More` button,
  and keyboard-only initial cursor highlighting.
- **History redesign**: framed day-section panels with accent headers and
  per-day counts, inline history filtering across `All`, `Account`, and
  `This device` modes, an unbroken `{count} in progress` resume summary, and
  aligned row-removal controls.
- **Watch later, Liked videos, and Playlists**: Watch later and Liked videos
  move from plain rows to responsive multi-column `video_card` grids with
  `Filter videos`, total duration summaries, and **Play all** from the visible
  list; Playlists uses stacked-tab cover cards with video-count pills, channel
  attribution, `Filter playlists`, and scrollable `Load more` pagination across
  all library views.
- **Interface and polish**: subtle surface elevation on built-in light/dark
  palettes, refined pill chips, top-bar and search suggestion polish, closer
  integration for video tabs and player controls, and preserved `horizontal_wrapped`
  spacing after `search_field` inputs.

Existing settings, local libraries and signed-in accounts remain supported;
no file or setting changes format.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64 (per-user NSIS `.exe`
installer and portable `.zip`); macOS 15+ Apple Silicon; locked Rust sources,
matching native sources, notices, channel manifests and SHA-256 checksums.

Native Linux requires glibc 2.39+, **system libmpv 0.42+ with Lua**, and current
yt-dlp/Deno. Windows/macOS bundle libmpv but still require external yt-dlp and
Deno. Flatpak includes its playback and extraction tools. Google Cast requires
`catt` installed separately. Channel manifests are submission inputs, not
evidence of publication in a package store.

## Not included

- New product features beyond those listed above: see [ROADMAP.md](https://github.com/bcosta19/youtfast/blob/v0.8.0/ROADMAP.md).
- Choosing an installed interface font on Windows and macOS.
- Bundled `yt-dlp`/`Deno` inside Windows release binaries (#56) or a bundled
  `catt` helper.
- Flathub or AUR store publication, Winget/Homebrew external repository
  acceptance, Windows publisher signing (Authenticode) or macOS notarization.
- Intel Macs, Windows ARM64, Linux ARM64, downloads or live chat.
- Completed interactive Windows/macOS platform qualification.

## Known limitations

- Older native libmpv versions remain unsupported even if the executable starts.
  Updating YouTFast does not update a native Linux system's libmpv; use a trusted
  current package or a Flatpak release containing the updated playback stack.
- YouTube changes can break extraction; keep yt-dlp current. Playback is
  signed out by default.
- Casting has not been qualified on physical Chromecast/Google TV devices or
  native Windows/macOS, and Flatpak TV discovery remains unqualified.
- Windows Credential Manager may reject sessions over its 2560-byte limit.
  Browser-session import additionally needs Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Windows/macOS automated builds and headless tests do not establish
  interactive playback, graphics or credential-store coverage. Platform QA
  remains tracked in [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
