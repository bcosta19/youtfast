# YouTFast 0.8.1

A maintenance release fixing missing characters and comment text.

## Included

- Fixes missing emoji, symbols, styled letters and kaomoji in titles, comments,
  descriptions and channel names. Platform colour emoji fonts are used when
  available; bundled fallbacks cover additional characters, including newer emoji.
- Preserves text around links and mentions when comment run boundaries fall
  inside an emoji.
- Updates the file-dialog and mDNS dependencies.

## Packages

Linux x86_64 native, Flatpak and Arch; Windows x86_64 installer and portable
ZIP; macOS 15+ Apple Silicon; corresponding sources, notices and checksums.
Native Linux needs libmpv 0.42+ with Lua and current yt-dlp and Deno;
Windows and macOS bundle libmpv but require yt-dlp and Deno separately.
Flatpak includes its playback and extraction tools.

## Not included

- Flathub or AUR publication, Windows publisher signing or macOS notarization.
- Intel macOS, Windows ARM64 or Linux ARM64 packages.
- Bundled yt-dlp and Deno in Windows packages, or a bundled Cast helper.

## Known limitations

- Windows and macOS automated builds do not establish interactive playback,
  graphics or credential-store coverage; platform QA remains tracked in
  [#5](https://github.com/bcosta19/youtfast/issues/5) and
  [#6](https://github.com/bcosta19/youtfast/issues/6).
- Windows Credential Manager may reject sessions larger than 2560 bytes.
  Browser-session import also requires Python and its yt_dlp module.
- Flatpak cannot read host browser profiles; use cookies.txt or stay signed out.
  The standalone Flatpak bundle has no automatic update remote.
- Casting remains unqualified on physical Chromecast and Google TV devices.
  YouTube changes can break playback extraction; keep yt-dlp current.
